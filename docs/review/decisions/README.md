# Architecture v5 설계 결정 기록

Material decision은 GitHub Issue에서 논의하고 focused PR로 번호 문서에 반영한다. 이 색인은 merge된 결정만 기록한다.

## 결정 상태

- `PROPOSED`: 선택지와 영향 검토 중
- `ACCEPTED`: 필수 reviewer가 승인하고 문서 PR이 merge됨
- `REJECTED`: 근거와 함께 채택하지 않음
- `DEFERRED`: owner, 사유와 다시 검토할 시점이 있음
- `SUPERSEDED`: 새 결정이 이전 결정을 대체함

## 필수 기록 항목

- ID와 제목
- Context와 문제
- 고려한 Options
- 보안·품질·비용·운영 trade-off
- 결정 owner와 필수 reviewer
- Outcome과 근거
- 영향을 받은 pipeline 단계·계약·문서
- 결정 Issue, PR와 commit SHA
- 후속 검증 또는 재검토 조건
