# R5-04 Human Review 자동화 제거 실행 계획

> 기준 설계: `docs/superpowers/specs/2026-09-03-r5-04-removal-design.md`

## 목표

Architecture v5의 Agent 자동화를 `ReportDraft` 생성에서 종료하고, Human Review·제출·공개를 사람 주도 외부 과정으로 분리한다.

## 작업 순서

1. 문서 검증기에 제거 계약 금지 규칙과 새 자동화 종료 경계 필수 규칙을 추가하고 기존 문서가 실패하는지 확인한다.
2. `08-lightweight-data-contracts.md`에서 Human Review 전용 식별자, 상태, action, requester, schema와 오류를 제거한다.
3. `ReportDraft`와 `AnalysisRunResult`에 출처, current revision, 제한사항, redaction과 자동화 종료 의미를 명시한다.
4. Overview, 역할, Gate·Reporter, 결과·관측성, 보안 경계, 마이그레이션, 보고서 템플릿을 같은 흐름으로 맞춘다.
5. 정본 Mermaid와 Wiki 복사본을 같은 블록으로 갱신한다.
6. Glossary, Governance, Issue 안내와 README를 새 R5 역할 범위로 맞춘다.
7. 과거 R4-03 spec과 plan에 대체 안내를 추가한다.
8. 제거 용어 검색, 문서 검증, `git diff --check`와 최종 diff 검토를 수행한다.
9. 두 개의 순차 커밋으로 기록하고 `origin/main`에 직접 push한다.

## 완료 조건

- 활성 설계 문서에 제거된 Human Review schema, action, state, decision, error가 남지 않는다.
- `ReportDraft`가 마지막 Agent 산출물임이 정본·Wiki·다이어그램에서 일치한다.
- `AnalysisRunResult`가 자동화 종료 결과 묶음으로 유지된다.
- Reporter 안전 요구사항 네 가지가 정본과 검증기에 존재한다.
- 보존 대상 계약의 이름과 검증 규칙이 유지된다.
- 전체 문서 검증과 Git diff 검사가 통과한다.
