## 재현된 엔진 한계

기존 정적 시험에서는 적용 가능한 97,328개 파일·규칙 조합 중 53,910개를 검증했다. 미검증 43,418개 중 42,953개는 당시 공유 실행시간 상한, 462개는 파싱·스캔 오류, 3개는 파일별 시간 초과였다. 이는 이번 시험의 최종 수치가 아니라 [이전 시험](2026-09-27-dify-static-coverage.md)의 기준점이다.

실제 Dify 단일 TypeScript 파일 `cli/src/sys/io/streams.ts`를 Semgrep으로 별도 실행했을 때에도 `PartialParsing`이 발생했고 파싱 비율은 98.2%였다. 원래 규칙은 이미 TypeScript 파일에 적용되고 있었으므로 규칙의 언어 목록에 `typescript`를 추가하는 것은 해결책이 아니다. `web/public/pdf.worker.min.mjs`의 미검증 세 규칙을 함께, 이어서 `auth-check` 하나만 `--timeout 30 --jobs 1`로 제한해 시험했으나 두 실행 모두 외부 120초 상한 안에 JSON을 내지 못했다. 단일 규칙 프로세스는 약 104 CPU초와 678 MB 작업 집합을 사용했다. 두 경우 모두 완료 증거가 아니며 해당 조합을 성공 처리하지 않는다.

## 현재 진행과 판정 원칙

누적시간을 무제한으로 둔 별도 정적 재시험은 2026-09-28 05:08 KST에 시작했다. 05:44 KST 기준 DB에는 이번 실행에서 새 요청 설명자가 있는 Semgrep 부분 스캔 17건과 호출 시간 초과 4건이 저장됐으며, 아직 최종 coverage artifact는 생성되지 않았다. 이후 요청 설명자와 원문 해시의 결합 및 구형 증거 복원 코드가 바뀌어, 해당 시험 프로세스만 종료하고 하위 스캐너가 남지 않은 것을 확인한 뒤 같은 시험 ID로 최신 코드를 재개했다. 06:28 KST에는 파일별 coverage 조회와 Semgrep 명령 계획의 반복 계산을 줄인 코드로 한 번 더 재개했다. 08:21 KST에는 저장소 루트를 파일마다 다시 확인하던 경로 검증 병목을 제거한 코드로 재개했고 실제 OpenGrep 프로세스가 시작된 것을 확인했다. 각 재개 전에는 이전 시험 프로세스와 하위 스캐너의 종료를 확인했으며 저장된 시도와 아티팩트는 지우지 않았다. 마지막 재개 직전 새 요청 설명자가 있는 Semgrep 부분 스캔은 34건, 호출 시간 초과는 4건이었다. 이 숫자는 진행 중인 시도 현황이지 검증된 조합 수나 최종 미검증 목록이 아니다.

OpenGrep이 실패해도 Python AST와 설정된 Python 범위 CodeQL 결과는 계속 수집한다. 그러나 이 결과를 JavaScript·TypeScript 규칙의 완료 증거로 대신 세지 않는다. 도구가 파일을 파싱하지 못하거나 유한한 호출 타임아웃에 걸린 조합은 정확한 경로·규칙·사유와 함께 `BLOCKED`로 남긴다. 정적 단계가 완전히 통과하기 전에는 A-007을 재개하지 않으며, Agent·Docker PoC·Finding·영문/한국어 제출 보고서가 나온 것으로 주장하지 않는다.

09:12 KST에는 Semgrep 하위 프로세스가 여러 차례 실행됐지만 DB에 새 시도가 기록되기 전, 결과 처리 중인 시험 프로세스의 CPU와 메모리 사용량이 계속 증가했다. 저장된 재사용 대상 Semgrep 원문 133개에는 결과 164,530개가 있지만 경로는 2,449종뿐이다. 이전 코드가 결과마다 Windows 실경로·심볼릭 링크·파일 여부를 반복 확인한 것이 재검증 병목이다. 동일 경로의 결과는 한 번 정규화하되 처리 마지막에 다시 검증하도록 수정하고 회귀 테스트를 추가했다. 이 수정 적용 전의 **시험 프로세스만** 정상 중단했고 하위 스캐너가 남지 않은 것을 확인했다. DB의 기존 성공·부분 결과와 artifact는 유지했다. 수정 후 같은 시험 ID로 재개해 최종 coverage artifact와 검증·미검증 조합 수를 이 문서에 추가해야 한다. 현재 실제 A-007은 `STATIC_DONE · BLOCKED`, 오류 `OPENGREP_PARTIAL_SCAN`이며 별도 시험 결과로 이를 성공 처리하지 않았다.
